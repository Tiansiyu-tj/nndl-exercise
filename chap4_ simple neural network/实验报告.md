# Chap4 实验报告

## 一、实验目的

本章实验主要包含两部分：

1. 使用全连接神经网络完成 MNIST 手写数字分类任务。
2. 利用两层 ReLU 网络完成一维函数拟合任务，并理解神经网络的非线性拟合能力。

通过本实验，可以加深对前向传播、反向传播、激活函数、交叉熵损失以及参数更新过程的理解。

## 二、实验内容与实现

### 1. MNIST 全连接神经网络分类

本实验分别使用 `NumPy` 和 `TensorFlow` 实现了一个两层全连接网络。

输入数据为 MNIST 灰度图像，尺寸为 `28 x 28`，在进入网络前先被拉平成 `784` 维向量，并做归一化处理：

- 原始像素范围：`[0, 255]`
- 归一化后范围：`[0, 1]`

网络结构如下：

1. 输入层：`784` 维
2. 隐藏层：`100` 个神经元，激活函数为 `ReLU`
3. 输出层：`10` 维，对应 `0-9` 十个类别
4. 输出后接 `Softmax`（输出函数）来进行分类概率计算，并使用交叉熵损失进行训练

其中，`NumPy` 版本手动实现了以下模块：

- `Matmul`
- `Relu`
- `Softmax`
- `Log`

并为它们分别编写了 `forward` 和 `backward`，再通过链式法则完成整个网络的反向传播。
`TensorFlow` 版本则使用自动求导完成梯度计算，更适合快速搭建和训练模型。

### 2. 基础函数实现练习

在 `tf2.0-exercise.ipynb` 中，手动实现了以下常见函数：

- `softmax`
- `sigmoid`
- `softmax` 交叉熵
- `sigmoid` 交叉熵

写代码时候考虑了数值稳定性，做了如下处理：

- `softmax` 中采用 `x - max(x)` 的形式避免指数溢出
- 交叉熵中加入很小的 `eps`，避免出现 `log(0)`

这些实现与 TensorFlow 自带函数进行了数值对照，误差控制在很小范围内。

### 3. 两层 ReLU 网络拟合函数

本次实验额外完成了函数拟合任务。自定义目标函数为：

```text
f(x) = sin(2x) + 0.3x^2
```

数据集构造方式如下：

- 训练集：在区间 `[-3, 3]` 内随机采样 256 个点
- 测试集：在区间 `[-3, 3]` 内均匀采样 256 个点

模型采用两层 ReLU 全连接网络：

```text
1 -> 64 -> ReLU -> 64 -> ReLU -> 1
```

损失函数为均方误差 `MSELoss`，优化器为 `Adam`，学习率为 `1e-3`。

## 三、实验结果

### 1. MNIST 分类结果

根据 notebook 中保存的输出结果：

- `NumPy` 版本在训练过程中准确率逐步提升，最终达到约 `80%` 左右
- `TensorFlow` 版本在 `500` 个 epoch 后测试集结果为：

```text
test loss 0.6878628 ; accuracy 0.8268
```

可以看出，使用自动求导的 TensorFlow 版本训练过程更稳定，代码实现也更简洁。

### 2. 函数拟合结果

函数拟合实验中，训练误差随 epoch 增加持续下降，保存输出如下：

```text
Epoch [500/3000], Train MSE: 0.007223
Epoch [1000/3000], Train MSE: 0.002031
Epoch [1500/3000], Train MSE: 0.000363
Epoch [2000/3000], Train MSE: 0.000115
Epoch [2500/3000], Train MSE: 0.000073
Epoch [3000/3000], Train MSE: 0.000060
Test MSE: 0.000062
```

从结果可以看出，该两层 ReLU 网络已经能够较好地逼近目标函数，说明带非线性激活的前馈神经网络具备较强的函数表示能力。

## 四、实验总结

本章实验让我从两个层面理解了前馈神经网络：

1. 从底层实现角度，掌握了前向传播、反向传播和梯度更新过程。
2. 从应用角度，验证了全连接网络在分类任务和函数拟合任务中的有效性。

总体来看：

- 全连接网络能够完成基本的手写数字识别任务
- 自动求导框架能显著简化模型训练过程
- 两层 ReLU 网络已经具备较强的非线性表达能力

后续若继续提升 MNIST 分类精度，可以考虑：

- 调整学习率和隐藏层宽度
- 使用更合适的初始化方式
- 增加训练轮数
- 使用卷积神经网络替代全连接网络
