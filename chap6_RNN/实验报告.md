# Chap6 实验报告

## 一、实验目的

本实验目标是使用循环神经网络（RNN/LSTM）完成中文唐诗生成任务，理解序列建模中“给定前文预测下一个字”的训练机制，并掌握文本数据预处理、字符级建模、训练与推理的完整流程。

具体目标如下：

1. 熟悉字符级语言模型的输入输出形式。
2. 掌握 LSTM 在长序列建模中的基本用法。
3. 实现以指定首字开头的诗句生成。
4. 分析训练与生成阶段常见问题，并提出改进方案。

## 二、实验原理

### 1. 任务建模

唐诗生成本质上是条件概率建模问题：

- 给定历史字符序列 `x1, x2, ..., xt`；
- 预测下一个字符 `xt+1`。

将整首诗看作一个字符序列，模型学习字符之间的统计依赖关系。

### 2. LSTM 网络结构

本实验采用两层 LSTM：

1. `Embedding` 层：将字符索引映射为稠密向量。
2. `LSTM` 层：提取上下文时序特征（2 层）。
3. `Linear` 层：将隐藏状态映射到词表维度。
4. `LogSoftmax`：输出每个字符的对数概率。

损失函数使用 `NLLLoss`，优化器使用 `RMSprop`。

### 3. 数据预处理策略

预处理时主要包含：

1. 清洗文本（去空格、过滤异常符号）。
2. 过滤长度过短或过长样本。
3. 为每条样本添加起止标记：`G`（start）和 `E`（end）。
4. 统计字符频次，建立 `word -> id` 映射。
5. 将诗句转为数字序列用于训练。

## 四、关键实现说明

### 1. 训练数据构造

在 `generate_batch` 中，输入 `x` 与标签 `y` 的关系为“右移一位”：

- `x = [w1, w2, w3, w4]`
- `y = [w2, w3, w4, w4]`

这样模型学习“当前字 -> 下一字”的映射关系。

### 2. 训练流程

在 `run_training()` 中执行：

1. 加载并向量化诗歌数据。
2. 构建 `Embedding + 2-layer LSTM + Linear` 模型。
3. 按 batch 循环训练，反向传播并更新参数。
4. 每隔一定 batch 保存参数到 `poem_generator_rnn`。

### 3. 生成流程

在 `gen_poem(begin_word)` 中执行：

1. 给定起始字（如“日”“红”“山”）。
2. 模型逐步预测下一个字并拼接。
3. 预测到结束标记或达到最大长度时停止。

## 五、实验结果

### 1. 训练现象

训练日志中可以观察到损失逐步下降并趋于稳定，示例：

```text
epoch 29 batch number 41 loss is: 5.6604
epoch 29 batch number 42 loss is: 5.6551
```

说明模型已学习到一定字符转移规律，但仍存在较大优化空间。

### 2. 生成样例（节选）

以指定首字进行生成，得到如下示例结果：

```text
日何年不见此，不觉人间事不同。
红树如珠翠，风吹玉阶开。
山川不觉长安客，日日西风吹玉楼。
夜秋来日暮时，山川无处不相疑。
```

可见模型已具备一定古诗风格表达能力，能生成基本通顺的短句。

## 六、问题分析与改进

实验中出现的典型问题：部分首字可生成、部分首字无输出或输出异常。

### 1. 可能原因

1. 数据解析鲁棒性不足：若直接使用 `split(':')`，遇到异常格式可能报错。
2. 生成可见性问题：打印函数对短句过滤过严，导致“实际生成了但未显示”。
3. 推理策略较贪心：容易提前预测结束标记，生成过短文本。
4. 模型容量与训练轮次有限：损失仍偏高，导致语义一致性不足。

### 2. 已改进源代码部分

1. 数据解析改为仅按首个冒号切分，提高鲁棒性。
2. 优化输出函数，避免因长度阈值导致结果被隐藏。
3. 生成时限制过早结束，延长最短有效长度。

## 七、实验总结

本实验完成了基于 PyTorch 的唐诗生成任务，跑通了从数据预处理、模型训练到条件生成的全流程。

通过实验我得到以下结论：

1. LSTM 能够学习字符级序列依赖，具备基础文本生成能力。
2. 文本任务中数据清洗与预处理对最终效果影响明显。
3. 当前模型可生成具有古诗形式特征的句子。
