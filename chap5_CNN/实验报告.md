# Chap5 实验报告

## 一、实验目的

本章实验的目标是利用卷积神经网络（CNN）完成 MNIST 手写数字分类任务，并理解卷积层、池化层和全连接层在图像识别中的作用。

相比全连接网络，卷积神经网络能够更有效地提取图像的局部空间特征，因此通常在图像任务上表现更好。

## 二、实验原理

卷积神经网络主要由以下几部分组成：

### 1. 卷积层

卷积层通过卷积核在图像上滑动，对局部区域进行特征提取。  
对于 MNIST 这类图像任务，卷积层可以提取边缘、笔画、局部形状等信息。

### 2. 激活函数

本实验中使用 `ReLU` 作为激活函数：

```text
ReLU(x) = max(0, x)
```

它能够增加网络的非线性表达能力，同时缓解梯度消失问题。

### 3. 池化层

池化层用于降低特征图尺寸，减少参数量与计算量，同时提升模型对平移和局部扰动的鲁棒性。  
本实验使用 `2 x 2` 最大池化。

### 4. 全连接层

卷积和池化提取出的高层特征最终通过全连接层映射到 `10` 个类别，输出每个数字类别的预测分数。

## 三、实验环境与数据集

### 1. 数据集

使用 MNIST 手写数字数据集：

- 训练集：60000 张
- 测试集：10000 张
- 图像大小：`28 x 28`
- 类别数：10

- `CNN_tensorflow.ipynb`

## 四、模型结构与实现

### 1. PyTorch 版本网络结构

根据 `CNN_pytorch.ipynb`，模型结构如下：

1. 第一层卷积：
   - 输入通道数：1
   - 输出通道数：32
   - 卷积核大小：`7 x 7`
   - 步长：1
   - padding：3
2. 最大池化：`2 x 2`
3. 第二层卷积：
   - 输入通道数：32
   - 输出通道数：64
   - 卷积核大小：`5 x 5`
   - 步长：1
   - padding：2
4. 最大池化：`2 x 2`
5. 全连接层：
   - `7 x 7 x 64 -> 1024`
   - `1024 -> 10`
6. Dropout：保留率约为 `0.7`

前向传播流程为：

```text
输入图像 -> 卷积1 -> ReLU -> 池化1 -> 卷积2 -> ReLU -> 池化2
-> 展平 -> 全连接1 -> ReLU -> Dropout -> 全连接2 -> 输出类别分数
```

### 2. TensorFlow 版本网络结构

在 `CNN_tensorflow.ipynb` 中实现了相同思路的两层卷积网络：

- 卷积层 1：`7 x 7 x 1 x 32`
- 卷积层 2：`5 x 5 x 32 x 64`
- 两次 `2 x 2` 最大池化
- 全连接层 `7 x 7 x 64 -> 1024`
- 输出层 `1024 -> 10`

损失函数采用交叉熵，优化器使用 `Adam`。

## 六、实验分析

### 1. 为什么 CNN 比全连接网络更适合图像

图像具有明显的二维空间结构，而全连接网络会直接把图像拉平成一维向量，容易丢失空间邻近关系。  
CNN 通过局部连接和权值共享，能够更自然地利用图像结构，因此参数更少、泛化能力更强。

### 2. 卷积核大小与通道数的作用

- 第一层使用较大的 `7 x 7` 卷积核，便于提取较粗的局部特征
- 第二层使用 `5 x 5` 卷积核，在更高层次上继续提取组合特征
- 通道数从 `32` 增加到 `64`，可以学习到更加丰富的特征表示

### 3. 池化与 Dropout 的作用

- 池化层减少特征图大小，降低计算开销，同时增强模型稳定性
- Dropout 可以缓解过拟合，提高模型在测试集上的泛化能力

### 4. 训练现象分析

从训练输出可以观察到：

- 在训练初期，准确率提升较快
- 中后期准确率逐渐趋于稳定
- 准确率达到较高水平后仍会有小幅波动，这是小批量训练和随机优化带来的正常现象

## 七、实验总结

本章实验完成了基于卷积神经网络的 MNIST 分类任务，并验证了 CNN 在图像识别问题上的有效性。

通过本实验，我获得了以下认识：

1. 卷积层能够自动提取图像局部特征。
2. 池化层能够降低维度并增强鲁棒性。
3. CNN 在图像分类任务上通常明显优于普通全连接网络。
4. 在 MNIST 数据集上，一个较浅的两层卷积网络就能够达到很高的识别精度。

若进一步改进模型，可以考虑：

- 调整卷积核数量和网络深度
- 使用 Batch Normalization
- 采用更系统的数据增强
- 在更复杂的数据集上测试模型性能，如 CIFAR-10
